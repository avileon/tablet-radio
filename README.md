# רדיו טאבלט (Kiosk)

אפליקציית אנדרואיד למסך יחיד: רדיו (גלגלצ, 99FM, 100FM + 10 ערוצי סגנון) וטלוויזיה (i24, ערוץ 14).

## התקנה
1. להוריד את ה-APK מ-**Releases** (נבנה אוטומטית בכל push ל-main).
2. להתקין בטאבלט (לאפשר "מקורות לא ידועים").
3. בפתיחה ראשונה: לאשר התראות, "התעלמות מאופטימיזציית סוללה", ו"הצמדת אפליקציה".
4. ללחוץ על כפתור הבית → לבחור **רדיו טאבלט** → **תמיד**.

## התנהגות
- לחיצה על תחנה → מנגן ברקע (Foreground Service), ממשיך גם כשהמסך כבוי.
- ניתוק רשת / תקלה → ניסיון חוזר אוטומטי + מעבר לכתובת גיבוי. Watchdog כל 10 שניות.
- אחרי הפעלה מחדש של הטאבלט → חוזר לתחנה האחרונה.
- טלוויזיה → הרדיו מושהה, ביציאה חוזר אוטומטית.

## יציאה ממצב קיוסק
לחיצה ארוכה על **השעון** (למעלה) → קוד `1234` → הגדרות / החלפת מסך בית.
הקוד מוגדר ב-`MainActivity.ADMIN_PIN`.

## נעילה מלאה (אופציונלי – Device Owner)
דורש טאבלט אחרי איפוס יצרן, בלי חשבון Google מחובר:
```
adb install TabletRadio-*.apk
adb shell dpm set-device-owner il.co.vibit.tabletradio/.AdminReceiver
```
ביטול: `adb shell dpm remove-active-admin il.co.vibit.tabletradio/.AdminReceiver` (לא תמיד אפשרי – אחרת איפוס יצרן).

## עריכת תחנות
`app/src/main/java/il/co/vibit/tabletradio/Stations.kt` — שינוי + push = APK חדש.
